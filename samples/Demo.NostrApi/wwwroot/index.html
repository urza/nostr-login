NIP-98 API demo

Each API call below is signed on its own by your NIP-07 extension. The server checks the URL, the method, the time and (for POST) the SHA-256 of the body. There is no session.

Most extensions ask you to approve each signature, unless you allow kind 27235 for this site. This is why NIP-98 fits API clients and bots better than normal browsing.
